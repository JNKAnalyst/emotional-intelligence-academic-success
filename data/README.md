# Data

This directory holds input data for the analysis.

## Files

- `sample_survey_data.csv` — small synthetic dataset (30 rows) used to illustrate
  the pipeline end-to-end. **Not real student data.** Generated by hand for
  demonstration only.
- `cleaned_survey_data.csv` — produced by `analysis/01_data_cleaning.R`.
- `features.csv` — produced by `analysis/02_nlp_processing.R`.

## Schema

| Column | Type | Description |
|---|---|---|
| `student_id` | string | Anonymous participant ID |
| `gpa_score` | numeric | Self-reported GPA on a 4.0 scale |
| `empathy_score` | numeric | Self-reported empathy (1–5 Likert composite) |
| `self_awareness` | numeric | Self-reported self-awareness (1–5 Likert composite) |
| `social_skills` | numeric | Self-reported social skills (1–5 Likert composite) |
| `open_response` | string | Free-text reflection on the academic term |

## Bringing your own data

Drop a CSV with the same schema in this folder and update
`config/config.R::DATA_PATH` to point to it. The cleaning script will validate
the columns and write `cleaned_survey_data.csv`.

Real student data is **not** included in this repository. Do not commit raw
identifiable responses; anonymize before sharing.
